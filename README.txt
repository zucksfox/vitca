NURVITA PORTOO

Cara menjalankan:
1. Extract ZIP.
2. Double-click index.html.
3. Mascot muncul di kiri bawah, menyapa, idle, dan blink random.
4. Klik mascot atau tombol Replay hello untuk mengulang sapaan.

File:
- index.html
- style.css
- script.js
- assets/nurvita-idle.png
- assets/nurvita-blink.png
- assets/nurvita-hello.png

Catatan:
Aset state hasil generasi tidak memiliki framing/pixel alignment yang 100% identik, jadi crossfade dipakai agar transisi terasa lebih halus. Untuk produksi terbaik, buat idle/blink/hello dari satu master sprite dengan canvas dan posisi karakter yang persis sama.
